Retail Sales EDA | DecodeLabs Project 2

About
An Exploratory Data Analysis (EDA) project using Python to analyze retail sales data, identify data quality issues, discover trends, and generate business insights.

Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Openpyxl

Key Tasks
- Data exploration and cleaning
- Missing values and duplicate detection
- Descriptive statistics (Mean, Median, Count)
- Outlier detection (IQR & Z-score)
- Pearson correlation analysis
- Sales trends and customer segmentation
- Data visualization and business insights

Visualizations
- Monthly Sales Trends
- Category Performance
- Revenue Distribution
- Outlier Analysis
- Correlation Heatmap
- Regional Sales
- Customer Segmentation

Objective
To transform raw retail data into meaningful insights through data cleaning, statistical analysis, and visualization.

Learning Outcomes
Practised Python, EDA, data preprocessing, statistical analysis, visualization, and analytical thinking.

Note:Dataset is simulated and results are illustrative.
